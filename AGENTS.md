# Экологический профиль Гомельщины

Запуск, тестирование и деплой описаны в [README.md](README.md). Проектные решения и дизайн описаны в [PROJECT.md](PROJECT.md).

## Данные и PocketBase

- У каждой публикуемой цифры должны быть источник и дата или период. Подписывай модельные данные как модельные. Помечай заглушки `[демо-данные]` и исключай их из продакшена. Справочники храни в PocketBase и `back/seed/`, контент редактируй через админку. При смене источника обновляй `sources` и страницу `/data`.
- Меняй схему через локальную админку PocketBase. Сохраняй сгенерированную миграцию вместе с изменением и запускай `npm run typegen` из `front/` на обновлённой локальной БД. `front/src/api/pocketbase-types.ts` генерируется автоматически.
- При изменении правил доступа или модерации проверяй затронутые сценарии на локальном PocketBase от нужных ролей, включая гостя и автора обращения. Интеграционные наборы, использующие один экземпляр PocketBase, запускай последовательно.

## Фронтенд

- Доступ к данным из компонентов проходит через `front/src/api/`. Держи `queryOptions` и хуки в модуле домена, начинай ключи запросов с имени домена. Используй строгий TypeScript без `any`.
- Используй токены из `front/src/styles/tokens.css` и общую обёртку `front/src/components/ui/tooltip.tsx` для подсказок. Учитывай `prefers-reduced-motion`. Проверяй затронутый сценарий на телефоне (375 px), а изменения главной ещё и на 1366×768. Цель Lighthouse Performance для главной — не ниже 85.
- Показывай пользовательский текст как текст. Форматированный редакторский HTML очищай через DOMPurify.
- Комментарии к коду пиши на английском, когда нужно объяснить причину решения.

## Совместная работа

- Для PR используй ветку `feat/*` с целью `main`, краткое описание и скриншот при изменении интерфейса. Префиксы коммитов — `feat:`, `fix:`, `chore:`, `docs:`.
- На общей машине соразмеряй число одновременных сборок и тестов с задачей. По возможности оставляй CPU и память другим процессам. Если тяжёлой задаче нужна вся машина, дай ей закончить перед запуском других тяжёлых проверок.
- Перед завершением останови фоновые процессы, которые запустил для задачи, и убери созданные тобой временные файлы, когда они больше не нужны.
