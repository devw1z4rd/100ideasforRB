## 1. Цель и границы

Поднять фронтенд-проект и собрать оболочку главной `/`: токены дизайна, шрифты, шапку, hero, футер, секции-якоря со скелетонами и маршруты-заглушки. Все остальные части главной встраиваются в эту оболочку отдельными подпроектами.

**Входит:**
- scaffold `front/` (Vite + React + TypeScript strict), Tailwind v4, shadcn/ui, Prettier, Vitest;
- токены из макета `temp-design/Main.dc.html` → `front/src/styles/tokens.css`;
- `SiteHeader` (три режима ширины), `MobileNav`, `Hero`, `SectionPlaceholder` ×4, `SiteFooter`;
- маршруты §11: `/` — главная, остальные — `StubPage`, неизвестный путь — `NotFoundPage`;
- `.gitattributes` (`eol=lf`), правки §7 и §10.1 в CLAUDE.md.

**Не входит:** запросы к API и PocketBase (кроме dev-прокси), содержимое секций карты, воздуха, предприятий и воды, авторизация, деплой, тёмная тема, PWA.

## 6. Компоненты

### `SiteHeader`

- `position: sticky; top: 0`, высота 56 px, фон `--bg`, нижняя граница `--border`, `z-index` выше содержимого.
- Порядок: `Logo` («Экология Гомельской области», ведёт на `/`) → якоря (Карта, Воздух, Предприятия, Вода) → вертикальный разделитель → страницы (Сравнение, Калькулятор, Новости, База знаний) → справа «Обновлено…» (если есть), кнопка «Сообщить о проблеме» (основная, `--fg`) и «Войти» (ghost).
- Prop `updatedAt?: Date`. Без него индикатор не рендерится. В подпроекте 1 prop не передаётся.
- Якоря — `<a href="/#map">`. На `/` клик прокручивает плавно (с учётом reduced-motion) и обновляет hash. С других страниц ведёт на `/#map`. У активного якоря `aria-current="location"`, цвет `--fg` и подчёркивание 2 px снизу. У неактивного цвет `--fg-muted`.
- Страницы — `NavLink`. У активной страницы `aria-current="page"` и цвет `--fg`.

**Режимы ширины.** Приоритет при сжатии такой: логотип → CTA → якоря → страницы.

| Ширина | Что видно |
|---|---|
| ≥ 1536 px | всё, как в макете |
| 1024–1535 px | страницы свёрнуты в `DropdownMenu` «Ещё ▾» |
| < 1024 px | логотип, компактная CTA «Сообщить» и бургер → `MobileNav` |

Границы режимов сверяются по реальной ширине содержимого. Критерий: на 1366 и 1024 px нет переноса строк и горизонтального скролла.

### `MobileNav`

Shadcn `Sheet` справа. Внутри три группы: «На главной» (якоря), «Разделы» (страницы), «Войти». Клик по пункту закрывает Sheet. Фокус удерживается внутри (Radix) и возвращается на бургер.

### `Hero`

- `<section id="top">` — на него ведёт «Наверх» в футере. Данные берутся из `content/hero.ts` (§7).
- Слева eyebrow (13 px, `--fg-muted`), H1 (§4), lead (16/1.55, `--fg-secondary`, `max-width: 70ch`). Числа в lead выделены (`tabular-nums`, `--fg`, 500). Под lead мелкая подпись: «Площадь и число районов: <publisher>, <year>», ссылка на источник.
- Справа мета-блок `<dl>` (13 px, сетка «ключ — значение»). Строки без значения не рендерятся. В подпроекте 1 есть одна строка: «Источники» → ссылка «Данные и методика» (`/data`).
- Отступы как в макете: `36px 40px 28px`. На ≥ 1024 px колонки стоят рядом с выравниванием по нижнему краю. Ниже 1024 px `dl` уходит под текст.

### `SectionPlaceholder`

```ts
type SectionPlaceholderProps = {
  id: "map" | "air" | "enterprises" | "water";
  eyebrow: string;
  title: string;
  tone: "light" | "dark";
  variant: "card" | "bleed"; // card — в контейнере со скруглением 16px (карта), bleed — во всю ширину (предприятия)
  minHeight: number;         // резерв высоты, чтобы якоря и подсветка вели себя как в готовой странице
};
```

`<section id aria-labelledby>`, `scroll-margin-top: 56px`, eyebrow + H2 (Inter Tight 600, 36–44 px), shadcn `Skeleton` заданной высоты, подпись «Раздел в разработке».

Секции на `HomePage`:

| id | eyebrow | Заголовок | Тон | `minHeight` |
|---|---|---|---|---|
| `map` | Карта | Карта экологической обстановки | dark, card | 680 (холст карты в макете) |
| `air` | Воздух | Качество атмосферного воздуха | light | 520 (график 400 + карточки, по макету) |
| `enterprises` | Предприятия | Предприятия и вклад в загрязнение | dark, bleed | 560 (оценка) |
| `water` | Вода | Состояние поверхностных вод | light | 360 (оценка) |

На мобиле (< 768 px) `minHeight` уменьшается вдвое.

### `SiteFooter`

Внутри: «© 2026 Экология Гомельской области»; ссылки «Данные и методика» (`/data`), «Вход для администратора» (`/_/`, обычный `<a>`), «Наверх» (к `#top`). Строки об авторстве нет (§16 №1). Пункта «Документация» нет: такой страницы нет в §11.

### `StubPage` и `NotFoundPage`

`StubPage` получает заголовок из `handle` маршрута и показывает H1 + «Раздел в разработке» + ссылку «← На главную». `NotFoundPage` показывает «Страница не найдена» и ту же ссылку. Обе страницы выставляют `document.title`.

### Прочее

- Первый элемент `<body>` — ссылка «К содержимому» → `#content`, видна только при фокусе.
- Видимое кольцо фокуса `--accent` на всех интерактивных элементах (`:focus-visible`).
- Появление секций: `motion` (`LazyMotion` + `domAnimation`, `m.section`), `opacity 0→1`, `y 8→0`, однократно (`viewport={{ once: true }}`). При `prefers-reduced-motion` анимации нет, `scroll-behavior` — `auto`.


**Сверка перед мержем.** Значения 40,4 тыс. км² и 21 район подтверждены вторичными источниками (Википедия, учебник географии на eior.by). Их нужно сверить по ежегоднику Главстата: он скачивается zip-архивом со страницы `factsSource.url`. Формулировку «крупнейшая область страны» нужно подтвердить сравнением площадей областей по данным Белстата. Если подтвердить нельзя, слово «крупнейшая» убирается. Если не подтверждаются сами цифры, lead переписывается без чисел.

`content/nav.ts` хранит массивы `anchors` (`{ id, label }`) и `pages` (`{ to, label }`), а также `cta` (`/reports/new`) и `login` (`/login`). Шапка, `MobileNav` и футер берут пункты только отсюда.

## 8. Логика активной секции

`lib/activeSection.ts`:

```ts
/** id последней секции, чей верх ушёл под шапку; null — если ни одна ещё не дошла (виден hero). */
export function pickActiveSection(
  sections: ReadonlyArray<{ id: string; top: number }>, // top — getBoundingClientRect().top, в порядке документа
  headerHeight: number,
  atBottom?: boolean, // страница докручена до конца
): string | null;

/** Хук: пересчитывает активную секцию на scroll/resize (passive, через requestAnimationFrame). */
export function useActiveSection(ids: readonly string[], headerHeight?: number): string | null;
```

Правило: активна последняя секция с `top <= headerHeight + 1`. При `atBottom` активна последняя секция списка, даже если её верх ещё ниже шапки. Короткая «Вода» в конце страницы иначе никогда не станет активной.

Тесты Vitest для `pickActiveSection`:
- все секции ниже шапки → `null`;
- верх первой ровно у шапки → `"map"`;
- прокручено между второй и третьей → `"air"`;
- `atBottom = true` при видимой последней → `"water"`;
- пустой список → `null`.

## 10. Риски

| Риск | Что делаем |
|---|---|
| Ширины шапки оценены на глаз | Границы режимов подбираются по факту; критерий в §6 |
| Точный порядок `shadcn init` для Tailwind v4 + Vite мог измениться | Перед scaffold сверить с актуальной документацией shadcn (context7) |
| Ежегодник не подтверждает цифры или «крупнейшая» | Убрать неподтверждённое из lead (§7) |
| CRLF в репозитории на Windows ломает скрипты в Docker | `.gitattributes`: `* text=auto eol=lf`, `*.exe binary` |
